# ProgettoFullStack

Progetto Full Stack sviluppato nell'ambito del corso di tirocinio **React / JavaScript Developer**.

## Descrizione

Applicazione full stack realizzata con React per il frontend e Node.js per il backend, sviluppata come progetto pratico durante il percorso di formazione.

## Installazione

```bash
# Clona il repository
git clone https://github.com/ilmuratore/progettofullstack.git

# Entra nella cartella del progetto
cd ProgettoFullStack

# Installa le dipendenze
npm install
```

## Avvio

```bash
# Avvia l'applicazione in modalità sviluppo
npm run dev
```
